# 项目当前状态

本文件仅记录公开网站的工程快照；长期约定见 [项目工程手册](项目工程手册.md)。

## 一、当前状态

- 官网为 Astro 静态站点，使用 GitHub Actions 构建并部署至 `https://hailinklabs.com`。
- 七个业务页面已完成中英文支持：原 URL 为默认英文，`/zh` 为简体中文；Header 可切换到当前页面的另一语言版本，404 提供两个首页入口。
- 英文公司名称统一为 Shenzhen Hailink Technology Co., Ltd.；中文使用深圳市海狸智联科技有限公司。Hailink Labs 和 Invoice Maker: SameJob 保持原名，产品仍为开发中，无下载入口。
- 公开仓库保存网站源码、公开内容、测试和必要工程说明；`internal/` 引用独立私有仓库。本次未修改私有资料或子模块引用。
- 构建与 CI 不拉取私有子模块，只发布 `dist/`；无新增依赖、后端、语言检测或语言偏好存储。

## 二、当前工作方向

### 中英文网站

- 共享七个页面组件、Layout、Product 与样式；英文原文作为类型约束的消息键，中文集中在 `src/data/zh.ts`，翻译仅在构建时执行。
- 两种语言的正文、导航、页脚、按钮、可访问性标签、title、description 和 Open Graph 已覆盖；每页 canonical 指向自身，hreflang 包含 `en`、`zh-CN`、`x-default`，默认指向英文。
- sitemap 包含全部 14 个正式 URL，保持根域、无 `.html`、非首页无尾斜杠、无重复 URL。
- Privacy 中文版覆盖原有 12 节，并说明差异以英文为准。英文正文在仅替换获批公司名称、忽略空白后与改造前基线一致，测试以全文 SHA-256 固定此约束；政策承诺和生效日期不变。
